# Awesome Kanban Board

Канбан-доска на React, созданная со структурой Create React App.

## Запуск

```bash
npm install
npm start
```

Приложение откроется по адресу `http://localhost:3000`.

## Возможности

- добавление задач в Backlog;
- перенос задач между колонками;
- сохранение всех изменений в localStorage;
- детальная страница и редактирование описания задачи;
- адаптивный интерфейс и меню пользователя.
